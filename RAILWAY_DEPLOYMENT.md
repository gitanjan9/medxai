# 🚂 Railway.app Deployment Guide

## Why Railway?
- **$5 free credit/month** (~500 hours of uptime)
- **Easy PostgreSQL setup** (included in free tier)
- **Simple deployment** from GitHub
- **Automatic HTTPS**

## 📋 Deployment Steps

### 1. Create Railway Account
1. Go to [railway.app](https://railway.app)
2. Sign up with GitHub
3. Verify email

### 2. Deploy from GitHub

#### **Option A: One-Click Deploy (Recommended)**

1. Push your code to GitHub (already done ✅)
2. Go to Railway Dashboard
3. Click **"New Project"**
4. Select **"Deploy from GitHub repo"**
5. Choose `gitanjan9/medxai`
6. Railway will auto-detect `railway.json` and deploy

#### **Option B: Railway CLI**

```bash
# Install Railway CLI
npm install -g @railway/cli

# Login
railway login

# Initialize project
railway init

# Link to your repo
railway link

# Deploy
railway up
```

### 3. Add PostgreSQL Database

1. In Railway Dashboard → Your Project
2. Click **"New"** → **"Database"** → **"PostgreSQL"**
3. Railway auto-creates `DATABASE_URL` environment variable
4. Your API will automatically connect to it

### 4. Set Environment Variables

In Railway Dashboard → Your Service → **Variables**:

```bash
# Required - Generate these first
JWT_SECRET_KEY=<run: openssl rand -hex 32>
MEDXAI_ADMIN_EMAIL=admin@yourdomain.com
MEDXAI_ADMIN_PASSWORD=<strong-password>

# Optional - Already set in railway.json
MEDXAI_ARCH=efficientnet_b3
MEDXAI_IMAGE_SIZE=320
MEDXAI_MODEL_VERSION=v2-efficientnet-b3-320
MEDXAI_PRIMARY_MODEL=txrv
COOKIE_SECURE=true
COOKIE_SAMESITE=lax

# CORS - Update with your frontend URL
CORS_ORIGINS=https://your-frontend.vercel.app

# Auto-set by Railway
DATABASE_URL=<auto-generated>
```

### 5. Add Persistent Storage (for model artifacts)

1. In Railway → Your Service → **Settings**
2. Scroll to **"Volumes"**
3. Click **"Add Volume"**
   - **Mount Path:** `/app/artifacts`
   - **Size:** 10 GB
4. Deploy will restart automatically

### 6. Upload Model Artifacts

**Option 1: Railway CLI**
```bash
# Connect to your service
railway shell

# Inside the shell, download artifacts
cd /app/artifacts
# Upload via scp or download from cloud storage
```

**Option 2: Add to Docker Image**
```bash
# If artifacts are small (<500MB), include in Docker build
# Already configured in Dockerfile.api
```

### 7. Get Your API URL

1. Railway Dashboard → Your Service
2. Click **"Settings"** → **"Domains"**
3. Railway provides: `https://medicalxai-production.up.railway.app`
4. Or add custom domain

## 🐛 Troubleshooting

### Issue: "Out of Memory"
**Solution:**
- Railway free tier has 1GB RAM (might be tight for PyTorch)
- Upgrade to Hobby plan ($5/month for 2GB RAM)
- Or reduce model size

### Issue: "Build Failed"
**Solution:**
- Check Railway logs
- Ensure `Dockerfile.api` exists
- Verify all dependencies in `requirements.txt`

### Issue: "Database Connection Failed"
**Solution:**
- Ensure PostgreSQL service is running
- Check `DATABASE_URL` is set
- Verify both services are in same project

### Issue: "Free Credit Exhausted"
**Solution:**
- Enable sleep mode (Settings → Sleep Mode)
- Upgrade to Hobby plan ($5/month)
- Or use Hugging Face Spaces (truly free)
